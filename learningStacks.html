📦 Stack & Queue

Stack and Queue are linear data structures that store elements in a specific order. They differ mainly in how elements are inserted and removed.

Stack

Stack follows the LIFO (Last In, First Out) principle. The last element added is the first one removed.

Stack Operations

  • Push – Insert an element
  • Pop – Remove the top element
  • Peek / Top – View the top element
  • isEmpty – Check if stack is empty

Applications of Stack

  • Function calls (call stack)
  • Expression evaluation
  • Undo / Redo operations
  • Backtracking problems

Queue

Queue follows the FIFO (First In, First Out) principle. The first element added is the first one removed.

Queue Operations

  • Enqueue – Insert an element
  • Dequeue – Remove an element
  • Front – Get front element
  • isEmpty – Check if queue is empty

Applications of Queue

  • CPU scheduling
  • Printer queue
  • Breadth First Search (BFS)
  • Handling requests in servers

Types of Queues

  • Simple Queue
  • Circular Queue
  • Priority Queue
  • Deque (Double Ended Queue)

Time Complexity

  • Stack operations: O(1)
  • Queue operations: O(1)

Common Problems

  • Valid Parentheses
  • Next Greater Element
  • Implement Stack using Queue
  • Sliding Window Maximum

Stack & Queue Algorithms – Code & Time Complexity

Stack and Queue are linear data structures used to store elements in a specific order. Their time complexity depends on how elements are inserted and removed.

Algorithm & Code Explanation & Time Complexity
Stack Push & Pop

push(x) {
  stack[++top] = x;
}

pop() {
  return stack[top--];
} 		Insert and remove elements only from the top.
No shifting or traversal required.
Constant number of CPU operations.
Time Complexity: O(1)
Queue Enqueue & Dequeue

enqueue(x) {
  queue[rear++] = x;
}

dequeue() {
  return queue[front++];
} 		Elements are added at rear and removed from front.
No element shifting is needed.
Each operation uses fixed steps.
Time Complexity: O(1)
Stack using Array

stack[size];
top = -1;
push(x); pop(); 		Direct index access allows constant operations.
Overflow and underflow must be checked.
Memory allocated at once.
Time Complexity: O(1)
Queue using Array

front = 0; rear = -1;
enqueue(x); dequeue(); 		Fixed-size array stores elements sequentially.
Circular queue avoids wasted space.
Constant-time insert and delete.
Time Complexity: O(1)
Valid Parentheses

for each char in string {
  if(open) push;
  if(close) pop;
} 		Each character is processed once.
Stack stores opening brackets.
Linear traversal dominates runtime.
Time Complexity: O(n)
Sliding Window Maximum

use deque to track max elements
remove smaller elements
 		Each element is added and removed once.
Efficient use of deque structure.
Avoids nested loops.
Time Complexity: O(n)

Stack and Queue operations are efficient because they restrict access to elements in a controlled order, ensuring constant-time insert and delete operations.
