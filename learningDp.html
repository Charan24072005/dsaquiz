🧩 Dynamic Programming (DP)

Dynamic Programming is an optimization technique used to solve problems by breaking them into overlapping subproblems and storing their results to avoid repeated computations.

Why Dynamic Programming is Important

  • Optimizes recursive solutions
  • Reduces exponential time to polynomial
  • Used in advanced problem solving
  • Very important for interviews

When to Use Dynamic Programming

DP is used when a problem has:

  • Overlapping subproblems
  • Optimal substructure

Types of Dynamic Programming

Top-Down Approach (Memoization)

The Top-Down approach solves the problem using recursion. It breaks the main problem into smaller subproblems and stores the result of each subproblem in a memory structure such as an array or map. Before solving any subproblem, it checks whether the result already exists. This avoids repeated computations and significantly improves performance. Memoization is especially useful when only a few subproblems are needed.

Bottom-Up Approach (Tabulation)

The Bottom-Up approach solves the problem iteratively. It starts by solving the smallest possible subproblems and stores their results in a table. These stored results are then used to build solutions for larger problems. This method avoids recursion and stack overhead, making it more efficient in terms of space usage.

Classic DP Examples

  • Fibonacci Numbers
  • 0/1 Knapsack Problem
  • Longest Common Subsequence (LCS)
  • Longest Increasing Subsequence (LIS)
  • Matrix Chain Multiplication

Dynamic Programming Algorithms – Code & Time Complexity

Dynamic Programming (DP) solves problems by breaking them into overlapping subproblems and storing their results to avoid repeated computation. Time complexity depends on the number of states and transitions.

Algorithm & Code Explanation & Time Complexity
Fibonacci (DP)

fib(n) {
  dp[0] = 0; dp[1] = 1;
  for(i = 2; i <= n; i++)
    dp[i] = dp[i-1] + dp[i-2];
  return dp[n];
} 		Each Fibonacci value is computed only once.
Loop runs from 2 to n.
Eliminates exponential recursive calls.
Time Complexity: O(n)
Space Complexity: O(n)
0/1 Knapsack

knapsack(W, wt, val) {
  for(i = 0; i <= n; i++) {
    for(w = 0; w <= W; w++) {
      dp[i][w] = max(...);
    }
  }
} 		DP table stores best value for each weight and item.
Two nested loops over items and capacity.
Total states = n × W.
Time Complexity: O(nW)
Space Complexity: O(nW)
Longest Common Subsequence (LCS)

LCS(s1, s2) {
  for(i = 1; i <= n; i++)
    for(j = 1; j <= m; j++)
      dp[i][j] = ...;
} 		Each state represents prefix comparison of strings.
DP table size = n × m.
All states computed once.
Time Complexity: O(nm)
Space Complexity: O(nm)
Longest Increasing Subsequence (LIS)

LIS(arr) {
  for(i = 0; i < n; i++)
    for(j = 0; j < i; j++)
      if(arr[j] < arr[i])
        dp[i] = max(...);
} 		For each element, all previous elements are checked.
Nested loops cause quadratic operations.
Time Complexity: O(n²)
Space Complexity: O(n)
Coin Change (Minimum Coins)

coinChange(coins, amount) {
  for(i = 1; i <= amount; i++)
    for(each coin)
      dp[i] = min(...);
} 		DP stores minimum coins for each amount.
Nested loops over amount and coin types.
Total states = amount × coins.
Time Complexity: O(n × amount)
Space Complexity: O(amount)

Dynamic Programming improves efficiency by avoiding repeated calculations. Proper state definition and transitions are key to optimal solutions.

Time and Space Complexity

Time complexity depends on the number of states and transitions. Space complexity depends on the DP table or recursion stack.

DP Optimization Techniques

  • Space optimization using rolling arrays
  • State compression
  • Eliminating unnecessary states

Common Mistakes in DP

  • Wrong state definition
  • Incorrect transition logic
  • Not handling base cases
  • Excessive memory usage

Dynamic Programming in Interviews

Interviewers expect you to explain state definition, transition, base case, and complexity clearly. Writing clean logic is more important than memorizing solutions.

Practice DP problems regularly to build confidence and improve logical thinking.
